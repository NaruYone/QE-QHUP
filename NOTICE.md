## Unwrap_TIE_DCT_Iter.m

`ppsh-zernike-phase-analysis/Unwrap_TIE_DCT_Iter.m` is an external phase-unwrapping implementation by Zixin Zhao, Xi'an Jiaotong University.

The original file header describes it as a robust 2D phase unwrapping algorithm based on the transport of intensity equation. Keep the original copyright notice, license terms, and source attribution when redistributing this file.
